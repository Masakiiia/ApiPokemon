## 1. Migrer vers express

Vous devez migrer votre mini-serveur vers express. Pour cela, vous allez vous baser sur le jeu de test que vous avez défini dans les exercices précédents (il est recommandé de travailler avec supertest)

### Livrable

## 2. Gestion des erreurs

Vous allez ajouter une gestion des erreurs. Au minimum, les cas suivants doivent être gérés : 
- 400
- 404
- 405
- 409
### Livrable
L'application express avec les erreurs ainsi que les tests qui les mettent en évidence

## 3. Gestion des logs

Vous allez ajouter des logs dans votre application pour tracer les différents appels et les erreurs qui peuvent se produire.
### Livrable
L'application avec des logs pour chaque erreur qui peut se produire et une information pour chaque route appelée.
Les logs doivent être sauvegardés dans un fichier de log.
